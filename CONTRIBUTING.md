# Contributing

Thanks for helping improve MathMate.

## Local setup

Follow the setup steps in [README.md](README.md). Keep API credentials in your local `.env` file; never include secrets, databases, recordings, or personal screenshots in a commit.

## Changes

- Keep changes focused and explain user-visible behavior in the pull request.
- For frontend changes, run `npm run lint` and `npm run build` from `frontend/` when practical.
- For API changes, describe any new environment variables and provider requirements.
- Do not claim compatibility with a note-taking site unless the feature has been verified on that site.

## Pull requests

Include a short summary, setup/configuration changes, and the verification you performed. Add screenshots for visual changes when useful. Never include `.env` contents or real API keys in logs, screenshots, commits, or pull requests.
